# Traffic findings

No evidence-backed daily traffic pattern can be reported from the retained dataset.

The run journal confirms only that the collector completed requests. It does not contain the returned traffic and no-traffic durations. Therefore morning peak, evening peak, midday behavior, late-night reset, weekday/weekend differences, persistent congestion, volatility, directional asymmetry, and top-25 rankings are all currently **UNKNOWN**.

The existing `public/link-marketplace/traffic-priors.json` contains two user-supplied local priors: weekday 16:00–18:00 for Malta commuter traffic and Sunday 17:00–20:00 for the Ċirkewwa ferry corridor. They remain labelled `LOCAL PRIOR` and must not be presented as measured findings.
